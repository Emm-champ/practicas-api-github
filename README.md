# Buscador de Películas con API

## Descripción
Este proyecto consiste en una aplicación web que permite buscar películas utilizando una API externa.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- GitHub
- API TMDB

## Funciones
- Buscar películas
- Mostrar descripción
- Mostrar imágenes
- Consumo de API
- Uso de JSON
